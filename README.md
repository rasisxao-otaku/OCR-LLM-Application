# OCR × LLM × RAG Document Assistant

## 概要

OCRとLLM、RAGを組み合わせた文書検索・質問応答システム。

PDFなどの文書からテキストを抽出し、Embeddingによるベクトル化と類似検索を通じて、文書の内容に基づいた回答を生成する。

LLM単体の知識に依存せず、外部文書を検索コンテキストとして利用する構成。

## システム構成

| 技術 | 用途 |
|---|---|
| C# / ASP.NET Core | メインAPI・アプリケーションロジック |
| Python | OCR処理 |
| Qdrant | ベクトルデータの保存・類似検索 |
| Ollama | Embedding・LLMの実行 |
| Docker Compose | 実行環境の構築 |

## 技術選定

### C# / ASP.NET Core

メインAPIには、実務経験の長いC#/.NETを採用。

API設計やアプリケーションロジックの実装に既存の知識を活かし、開発効率と保守性を確保する。

### Python

OCR処理にはPythonを採用。

OCR・画像処理・機械学習関連のライブラリが豊富であり、文書解析を行う上で選択肢が多い点を評価した。

### サービス分離

メインAPIとOCR処理を分離し、それぞれの責務を明確化。

技術スタックの異なる処理を独立させることで、OCRエンジンの変更や機能追加による影響範囲を抑えやすい構成とした。

## 処理フロー

### 文書登録

1. PDFの入力
2. OCRによるテキスト抽出
3. 抽出テキストのチャンク分割
4. Embeddingによるベクトル化
5. Qdrantへの登録

### 質問応答

1. ユーザーから質問を受け付ける
2. 質問文をEmbedding
3. Qdrantから関連情報を検索
4. 検索結果をコンテキストとしてLLMに渡す
5. LLMによる回答生成

※各工程の実装状況に合わせて記載を調整する。
